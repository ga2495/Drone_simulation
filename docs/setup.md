# Setup Checklist

## Python

- Python 3.10+ recommended.
- Create a virtual environment.
- Install `simulator/requirements.txt`.
- Start `simulator.py`.

## Frontend

- Node.js 18+ recommended.
- Run `npm install`.
- Run `npm run dev`.

## Backend

- Run `npm install`.
- Run `npm start` when image/data ingestion is needed.

## Development rule

Do not commit `node_modules`, Python virtual environments, build outputs, local uploads, or secrets.
