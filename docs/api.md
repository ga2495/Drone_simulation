# API Reference

## Simulator API

The Flask simulator exposes the endpoints implemented in `simulator.py`, including:

- `GET /`
- `GET /status`
- `GET /frames`
- `GET /latest`
- `GET /start`
- `GET /stop`

Check the implementation for the exact response schema and query parameters.

## Ingestion API

The Node service exposes the upload route implemented in `backend/server.js`. Use the source as the authoritative request schema.
